# Greeting Acceptance

1. In the selected environment, open the client against the intended API.
2. Enter `Casey`. Expect `Hello, Casey!` with a successful exit.
3. Send the resulting greeting to the worker. Expect an accepted receipt with the
   same message.
4. Record the tested client, API, and worker versions, environment, time and result.
5. Confirm which customers can access the released capability before using it in
   external material.

The local example exercises the journey with a loopback API, a real client and a worker.
Staging and production each require their own evidence.
